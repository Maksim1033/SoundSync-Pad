**SoundSync Pad** - саундборд прямого подключения для пати, где аудио воспроизводится локально на ПК каждого участника. 

Вместо трансляции звука через виртуальные микрофоны, приложение синхронизирует файлы между друзьями и использует быстрые RPC триггеры. Это позволяет полностью обойти шумоподавление Дискорда и внутриигровых чатов, сохраняя звук без обрывов.
